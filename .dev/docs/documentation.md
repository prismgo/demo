# 文档维护导航

## 文档位置

| 路径 | 内容 |
|---|---|
| `docs/zh_CN/` | 中文文档 |
| `docs/en/` | 英文文档 |
| `docs/README.md` | 文档仓库中文入口 |
| `docs/README_en.md` | 文档仓库英文入口 |

## 维护规则

- 文档描述必须与当前 `framework/` 的实际 API 和行为一致。
- 新增或调整用户可见能力时，检查中英文文档是否需要同步。
- 命令、包名、配置键和代码示例应从源码核对，不凭记忆填写。
- 保持现有导航结构和写作风格；不要在文档仓库混入框架实现。
- 框架变更日志仍按 `framework/AGENTS.md` 指定的位置与格式维护。
